# Support

- Use [GitHub Discussions](https://github.com/Sentinel3252/DistLLM/discussions) for setup help, design questions, and usage ideas.
- Use [GitHub Issues](https://github.com/Sentinel3252/DistLLM/issues) for reproducible bugs and scoped feature requests.
- Use private vulnerability reporting for security issues, as described in [SECURITY.md](SECURITY.md).

When asking for help, include the operating system, Python and PyTorch versions, backend, world size, command, and complete error message. For GPU problems, also include the GPU model, driver, CUDA runtime, and whether the failure occurs with Gloo or NCCL.

This is a community-maintained project. Response times are best effort, and there is no service-level agreement.
